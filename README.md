# Panel de demurrage CCTI

Vista operativa del estado de demurrage de los contenedores CCTI.

**Los datos están cifrados (AES-256-GCM).** Este repositorio solo contiene el
bloque cifrado; sin la clave no se puede leer nada. La clave no está acá y no se
envía a ningún servidor: el descifrado ocurre en el navegador de quien la ingresa.

- `index.html` — panel (cliente)
- `datos.enc.json` — datos cifrados
